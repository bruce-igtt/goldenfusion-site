BEFORE YOU BEGIN

What you'll need

Choose Apple, Android, or both. Begin with the phone you can test most easily.

A capable computer

iPhone development needs a Mac that can run the current Xcode. Android development needs a computer that meets Android Studio's current requirements.

Developer accounts

Apple's program is $99 per membership year; Google Play Console is $25 one time in the US. Check current terms before enrolling.

A real test phone

Use an iPhone, Android phone, or both to find issues that a computer simulator may miss.

Time to test and revise

ChatGPT can help write and explain code. You make the product decisions, run the app, and verify each result.

Questions before you begin

Do I need to know how to code?

No coding background is needed to start the guide. You will still need to follow instructions carefully, run the app, test it, and make decisions. Some apps require expert review.

Does the guide build my app for me?

It gives you a process and prompts to use with ChatGPT. It does not include custom code for your specific idea or a guarantee of store approval.

Can I build for Apple and Android?

Yes. The guide covers both paths and recommends getting one small version working first. The two platforms need separate builds and tests.
